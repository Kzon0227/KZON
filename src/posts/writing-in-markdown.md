title: Writing in Markdown
description: A quick reference for the Markdown syntax this blog supports.
date: 2026-10-20
---

Posts are written in standard Markdown. A few of the basics:

- **Bold** and *italic* text
- [Links](https://www.11ty.dev/) to other pages
- Bulleted and numbered lists
- Code blocks with syntax highlighting

```js
console.log("Hello from a code block");
```

> Blockquotes work too, if you want to call something out.

Headings, images, and tables are all supported as well — write naturally and
the site will take care of the formatting.
