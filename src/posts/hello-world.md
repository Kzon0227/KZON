Welcome to the KZON blog. This site is built with [Eleventy](https://www.11ty.dev/),
a simple static site generator, and deployed for free on GitHub Pages.

Every post lives as a Markdown file in `src/posts/`. To write a new one, copy
this file, give it a new filename, and fill in the front matter at the top:

```yaml
---
title: Your Post Title
description: A one-line summary for the homepage.
date: 2026-11-01
---
```

Then write the body in Markdown below the front matter. Run `npm run serve`
to preview it locally before publishing.
